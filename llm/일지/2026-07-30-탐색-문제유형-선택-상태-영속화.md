# 2026-07-30 탐색 문제유형 선택 상태 영속화

## 문제

탐색 페이지의 문제유형 선택 상태가 페이지 진입 시마다 전체 선택으로 초기화됐다.

## 해결

`useExplore`에서 `checkedTypes`를 Local Storage(키 `explore/checkedTypes`, `consts.ts`의 `CHECKED_TYPES_STORAGE_KEY`)에 저장/복원한다. 초기값은 `useState(loadCheckedTypes)` lazy init으로 읽고, `appliedTypes` ref도 같은 값으로 시작한다. 복원 시 `AllQuestionTypes.filter((type) => parsed.includes(type))`로 유효한 유형만 남겨, 저장된 쓰레기 값이나 제거된 유형이 유입되지 않게 했다(파싱 실패 시 전체 선택으로 폴백). 저장은 `updateCheckedTypes`에서 수행한다. 사용자가 전부 해제한 상태도 그대로 복원된다.
