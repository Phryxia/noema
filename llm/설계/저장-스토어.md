# 개요

데이터 종류별 Store의 스키마와 조작 절차를 서술한다.

- 상위문서: [기획](../기획.md)
- DB 이름/버전, 스키마 생성, ID·날짜·트랜잭션·인덱스 공통 규약은 [저장 공통 규약](../기획/저장-공통.md)에 있다.
- 하위문서:
  - [단어 Store](./저장-단어.md): `wordMeta`, `wordNodes`, `recentWords`
  - [문장 Store](./저장-문장.md): `sentences`, `recentSentences`
  - [문서 Store](./저장-문서.md): `documents`, `recentDocuments`
  - [탐색 Store](./저장-탐색.md): `questions`, `relations`
