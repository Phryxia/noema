# 단어의 경우

- 상위문서: [타입별 Store](./저장-스토어.md)

## Word Meta Store

스토어 이름은 `wordMeta`. Key Path를 가지지 않으며, 정해진 키는 다음과 같다.

- `trieNodeSize`
  - 총 기록된 노드 수 (루트 포함)
  - 기본값 1
  - 노드 삭제 시 감소
- `wordSize`
  - 총 기록된 단어 수
  - 기본값 0 (루트는 단어가 아님)
- `nextNodeId`
  - 다음에 발급할 `nodeId`
  - 기본값 1 (루트가 0을 차지)
  - 노드 생성 시 이 값을 쓰고 1 증가시키며, 삭제해도 되돌아가지 않는다

## Word Store

Store 이름은 `wordNodes`. Key Path로 `nodeId`를 갖는다.

```ts
interface TrieNode {
  // 이 Trie Node를 식별하는 unique한 숫자
  // auto increment
  nodeId: number
  // 이 TrieNode의 부모의 nodeId. 루트이면 undefined.
  parentNodeId?: number
  // parent에서 이 노드로 오는 길이 1의 UTF-8 문자. 루트이면 빈 문자열.
  value: string
  // 길이 1의 UTF-8 문자에 대응되는 자식들의 id
  children: Record<string, number>
  // isEnd를 겸한다. 특정 단어가 주입된 시각을 저장한다.
  createdAt?: Date
}
```

`wordNodes`가 비어있으면 루트노드(`nodeId`는 0, `value`는 빈 문자열, `children`은 빈 객체)를 먼저 넣는다.

단어 문자열과 `nodeId`는 다음과 같이 오간다. 라우트가 `/word/[:word]`이므로 이 변환은 페이지 진입마다 일어난다.

- 문자열에서 `nodeId`로: 루트에서 시작해 문자를 하나씩 `children`으로 따라 내려간다. 도중에 끊기면 없는 단어다. 길이가 L인 단어라면 L+1번의 `get`이 필요하다.
- `nodeId`에서 문자열로: `parentNodeId`를 루트까지 거슬러 오르며 `value`를 모은 뒤 뒤집는다.
- 접두사 나열(`WordSuggestion`)은 접두사에 해당하는 노드를 찾은 뒤, 거기서 DFS로 내려가며 경로 문자열을 누적한다. `createdAt`이 있는 노드만 단어다.

## 단어 삭제 규칙

단어 삭제 시 Trie도 정리한다.

1. 해당 노드의 `createdAt`을 제거하고 `wordSize`를 1 줄인다.
2. 그 노드에 `createdAt`도 없고 `children`도 비어있으면, 부모의 `children`에서 자신을 지운 뒤 Store에서 제거하고 `trieNodeSize`를 1 줄인다.
3. 부모에 대해 2를 반복한다. 루트노드는 제거하지 않는다.

## 최근 추가된 단어

최근에 추가된 단어는 최대 10개까지 보관하는데 이는 별도 Store가 필요하다.
순환 큐처럼 다룬다.

Store 이름은 `recentWords`. Key Path를 가지지 않으며, 정해진 키는 다음과 같다.

- `0` ~ `9`: 추가된 단어 최대 10개에 대응되는 인덱스. 만약 아직 존재하지 않거나 삭제됐으면 값이 `null`일 수 있다.
- `next`: 최초에 `0`. `wordNodes`에 단어가 추가되면 `recentWords[recentWords.next]`에 `RecentWord`를 쓴 뒤 1을 더하고 10으로 나눈 나머지로 갱신한다.

```ts
interface RecentWord {
  // TrieNode의 ID
  nodeId: number
  // 해당 TrieNode가 표현하는 총 문자열 (ex: apple)
  value: string
  // 추가한 시각
  createdAt: Date
}
```

읽을 때는 `next - 1`부터 역방향으로 순회하여 최근 순으로 얻는다. `null`인 칸은 건너뛴다.
