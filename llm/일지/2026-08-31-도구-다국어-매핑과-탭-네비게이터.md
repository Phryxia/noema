# 2026-08-31 도구 다국어 매핑과 탭 네비게이터

## 문제

`/tools`에 두 번째 도구 "다국어 매핑"을 넣어야 했다. 가변행렬(열=언어, 행=같은 의미 단어)에 단어를 적으면 같은 행의 단어쌍을 상대 열의 언어 이름을 `word3`으로 하는 관계 짓기로 일괄 연결하고, 완료 시 신규 단어와 추가된 관계 수를 모달로 보여준다. 도구가 둘이 되므로 `?tab=` 쿼리로 구동되는 서브 네비게이터도 필요했다.

## 해결

- 신규 단어 판별: `createWord`가 `addWord`의 `isCreated`를 버리고 있어, 본문을 `upsertWord`로 추출하고 `createWord`를 위임으로 바꿨다. `getWordNodeId` 사전 조회 안은 단어당 트랜잭션이 2회가 되고 조회-생성 사이 비원자성이 생겨 기각.
- 관계 생성: `submitNamedAssociations`의 비공개 `submitTuple`을 `submitNamedAssociation.ts`로 추출해 공용화했다. 함수 재사용 안은 "전부 중복이면 throw"가 "관계 0개여도 모달" 요구와 충돌해 기각. 별도 구현 안은 중복 조회·출처 접두·결과 조립이 복제되어 기각.
- 튜플은 값 삼중쌍 기준으로 사전 dedup한다(`computeMappingTuples`, 구분자 `\t`은 입력이 차단되어 안전). 없으면 두 데이터 행이 같은 쌍을 담을 때 두 번째가 DB 조회에서 '중복'으로 잡혀 개수 집계가 흐려진다. `(j,k)`와 `(k,j)`는 `word3`이 달라 서로 다른 관계이므로 둘 다 만든다.
- 커서 이동은 `computeMatrixNavigation` 순수 함수로 분리해 vitest로 고정했다(`extraction/arrowNavigation.ts`의 인자 주입 방식). Tab은 "오른쪽 키와 동일"을 도착지 기준으로 해석해 캐럿 위치와 무관하게 다음 칸 처음으로 보냈다. Tab의 기본 동작 자체가 캐럿 이동이 아니기 때문이다.
- 마지막 행의 Enter는 "이동할 칸이 없으면 기본 동작" 규칙의 예외로 삼켰다. 기본 동작이 폼 암묵 제출이라 회피성 적재로 이어진다. 제출은 명시 버튼만이라는 기존 규칙을 따랐다(`TitleField`가 Enter를 삼키는 전례).
- 제출 흐름은 `useMutation` 직접 사용. `useBatchSubmission`은 결과형이 `BatchResultEntry[]`이고 성공 토스트 전제라 맞지 않았다. `meta.successMessage`도 두지 않았다. 저장성 mutation이지만 모달이 피드백을 전담한다는 판단이다.
- 리셋은 `onSuccess`에서 즉시, 포커스는 모달 닫기(`closeResult`)에서 `focusFirstElement` 먼저 -> `setResult(null)` 나중 순으로 했다. 닫기 버튼에 포커스가 있는 채 dialog가 언마운트되면 포커스가 `body`로 떨어지기 때문이다.
- sticky 제출 행은 `WriterActions`를 재사용하지 않고 CSS 패턴만 복제했다. `onDelete` 필수 prop과 수정/저장 라벨이 맞지 않고, 이를 prop으로 벌리는 일반화는 범위를 벗어난다고 봤다.
- 탭 UI는 `explore/ChoiceGroup` 재사용. `role=tablist` 전례가 없고 전환이 URL 내비게이션이라 토글 버튼 시맨틱이 실체와 맞다.
- `?tab=`은 `validateSearch`에서 `'i18n'`만 유효 키로 남겼는데, playwright 검증에서 `?tab=garbage` 직접 진입 시 `getRouteApi('/tools').useSearch()`가 원본 `'garbage'`를 그대로 돌려주는 것을 발견했다. strict useSearch도 원본을 줄 수 있어 `ToolsPage`에서 `tab === 'i18n'`으로 재검증한다.
- 두 도구가 같은 한 줄 핸들러를 갖게 되어 `keepFieldFocus`를 `tools/keepFieldFocus.ts`로 추출했다.

## 남은 것

- 다국어 매핑의 열이 아주 많아지면 가로 스크롤(`overflow-x: auto`)만 있고 열 고정은 없다.
- 관계 삽입 실패(`failure`)는 모달에 드러나지 않는다. 성공 수만 센다.
