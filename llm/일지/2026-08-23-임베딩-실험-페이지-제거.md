# 2026-08-23 임베딩 실험 페이지 제거

## 문제

`/lab/embedding` 임베딩 실험 페이지는 오래 쓰지 않았고 성능도 좋지 않았다. 실험은 NOEMA 방향성
조정에 맞춰 별도 패키지로 재구성할 예정이라 클라이언트에서 걷어내기로 했다.

## 해결

- 삭제: `src/lab/` 전체(테스트 6개 포함), `routes/lab.embedding.tsx`, `word/getWordTrie.ts`
  (lab만 import), `__root.tsx`의 `실험` 링크. `routeTree.gen.ts`는 빌드로 재생성.
- `useExplore`의 `ExploreOptions`에서 lab만 쓰던 `checkedTypesStorageKey`·`pickQuestion`·`queryKey`를
  제거했다. 탐색·문서 작성기는 기본값 경로만 쓰므로 동작 변화 없음. 무응답 제출(`answer: null`)은
  탐색에도 적용된 스펙이라 유지.
- `src/storage/clearLegacyStorage.ts`를 `main.tsx` 기동 시 호출해 `lab/embedding/` 접두사 localStorage
  키(`models`, `checkedTypes`)를 지운다. 실험 코드는 IndexedDB를 읽기만 했으므로 DB는 손대지 않았다.
- 외부 ML 라이브러리는 없었고 `chart.js`는 통계 차트가 공유하므로 의존성 변경 없음.
- 기획 문서 `기획/탐색-임베딩실험.md`도 삭제했다. 과거 history의 링크는 끊어진 채 둔다.
- 검증: tsc, eslint, vitest 16파일 99개 통과. `lab/embedding|getWordTrie|LabEmbedding` grep 0건.
