# 대시보드

`/`. 입력 구역, 최근에 추가된 것들, 통계 구역. 공통 헤더의 `NOEMA System` 제목 링크로 들어간다.

## 코드

- 페이지: `routes/index.tsx`(`MainPage`, 로컬 `WriterSection`)
- 최근 목록 묶음: `recent/RecentCreations.tsx` -> `word/RecentWords`, `sentence/RecentSentences`, `document/RecentDocuments`, 공용 줄 `recent/RecentLines`
- 통계: `statistic/Statistic/Statistic.tsx`([통계](./통계.md))
- 모드: `writer/consts.ts`의 `WriterModes`, `shared/RadioGroup`

## 사양

- 입력 구역: 라디오 `단어`/`문장`/`문서`(지역 상태, 기본 `단어`). 모드에 따라 `WordWriter`/`SentenceWriter`/`DocumentWriter`를 편집 가능으로 그린다. 각 입력기는 [단어](./단어.md), [문장](./문장.md), [문서](./문서.md).
- 최근에 추가된 것들: 세 헤더는 [최근-목록](./최근-목록.md)의 세 페이지로 가는 링크. 단어는 최대 10개를 inline flex로 최근순, 문장은 최대 4개를 한 줄에 하나(CSS 줄임표), 문서는 최대 4개를 초입 64자로 한 줄(CSS 줄임표). 모두 개별 페이지 링크. 순환 큐 사본을 읽는다.
- 통계 구역: [통계](./통계.md).

## 결정 근거와 제약

- 순환 큐 사본을 읽는 이유: 원본 Store의 커서를 매번 열지 않고 대시보드를 가볍게 한다. 그보다 과거는 최근 목록 페이지가 원본을 훑는다.
- `WriterSection`은 페이지 로컬 함수다. 모드 선택기를 공용 `WriterModeSelector`로 올렸던 시기가 있었으나 지금은 `shared/RadioGroup`이 그 역할이다.

## 알려진 함정

- 최근 문장·문서 줄의 bullet 제거는 `global.css`의 `:where(.pico ul)` 규칙에 의존한다. [UI개발참고](../참고/UI개발참고.md#specificity-함정-가장-자주-터진다)
