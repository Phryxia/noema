# 개요

페이지의 라우트와 구성을 서술한다.

- 상위문서: [화면](./화면.md)
- 페이지가 배치하는 컴포넌트의 동작은 [재사용 컴포넌트](./화면-컴포넌트.md)에 있다.
- 페이지가 읽고 쓰는 데이터의 스키마는 [타입별 Store](../설계/저장-스토어.md)에 있다.

# 공통 규칙

이 구획의 2-depth 헤더의 내용은 하단의 페이지별 기획에서 각 호를 언급할 때 적용된다.

## 미저장 수정 이탈 질의

- 값은 수정돼 있는데 수정 버튼을 누르지 않은 상태로 이탈을 시도할 경우
  - 표준 프롬프트 화면으로 `수정된 내용을 저장할까요?` 물어보며 확인
  - confirm인 경우 수정 반영
  - cancel인 경우 수정 없이 그대로 이탈

# 페이지

## 메인

- 라우트: `/`

메인 페이지는 다음 요소로 구성된다.

- 입력 섹션(`WriterSection`)
  - 모드 선택(`WriterModeSelector`)
    - 라디오 버튼
    - `단어`, `문장`, `문서`
  - 모드가 `단어`인 경우 `WordWriter`
  - 모드가 `문장`인 경우 `SentenceWriter`
  - 모드가 `문서`인 경우 `DocumentWriter`
- 최근에 추가된 단어(`RecentWords`)
  - 최대 10개
  - inline flex로 가장 최근에 추가된 순으로 나열
  - 링크로 작성되며, 클릭 시 해당 단어 페이지로 이동한다.
- 최근에 추가된 문장(`RecentSentence`)
  - 최대 4개
  - 한 줄에 한 문장씩
  - wrap으로 넘어가지 않도록 너무 길면 줄임표 (CSS로)
  - 링크로 작성되며, 클릭 시 해당 문장 페이지로 이동한다.
- 최근에 추가된 문서(`RecentDocument`)
  - 최대 4개
  - 한 줄에 문서의 초입부분의 64글자
  - wrap으로 넘어가지 않도록 너무 길면 줄임표 (CSS로)
  - 링크로 작성되며, 클릭 시 해당 문서 페이지로 이동한다.

## 개별 단어

- 라우트: `/word/[:word]`
- `WordWriter`에 해당 단어 입력돼 있음
- id 표시
- 수정 버튼
  - 폼의 수정 사항이 있을 때만 활성화
  - 누를 시 수정 반영
- 삭제 버튼
  - 누를 시 삭제 후 메인 페이지로 이동
  - 해당 단어 노드 참조하는 `Relation` 비동기 삭제
  - 최근에 추가된 단어에 해당 단어 있으면 삭제
- _미저장 수정 이탈 질의_ 적용

## 개별 문장

- 라우트: `/sentence/[:sentenceId]`
- 문장 내용 표시
- 수정 버튼
  - 폼의 수정 사항이 있을 때만 활성화
  - 누를 시 수정 반영
- 삭제 버튼
  - 누를 시 삭제 반영 기다린 후 메인 페이지로 이동
  - 해당 문장 참조하는 `Relation` 비동기 삭제
- _미저장 수정 이탈 질의_ 적용

## 개별 문서

- 라우트: `/document/[:documentId]`
- 문서 내용 표시
- 수정 버튼
  - 누를 시 수정 반영
- 삭제 버튼
  - 누를 시 삭제 반영 기다린 후 메인 페이지로 이동
  - 해당 문서 참조하는 `Relation` 비동기 삭제
