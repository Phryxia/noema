# 기능 문서의 절

모든 `기능/*.md`는 `코드`, `사양`, `결정 근거와 제약`, `알려진 함정`, `관련 문서`, `일지` 순이다. `코드` 절의 경로는 `packages/client/src/` 기준이다. 스키마·타입·상수 값은 문서에 베끼지 않고 파일을 가리킨다.
