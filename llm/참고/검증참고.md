# 검증 참고

작업을 마치고 확인할 때 읽는 문서다. 명령은 모두 저장소 루트에서 실행한다.

# 정적 검사

- 타입: `npx tsc -b packages/client/tsconfig.app.json`
- 린트·포맷: `npx eslint packages/client/src`, `npx prettier --check packages/client/src`
- `routeTree.gen.ts`는 git에 없고 vite 플러그인이 만든다. 라우트 파일을 바꿨는데 개발서버가 꺼져 있으면 `npx vite build`(또는 `npm run build`)를 먼저 돌려야 `tsc`가 통과한다.

# 단위 테스트

- `npm test`(루트) 또는 `npx vitest run`(`packages/client`). 테스트는 순수 함수 옆에 `*.test.ts`로 둔다(약 20파일). 브라우저 API·IndexedDB가 필요한 코드는 vitest로 검증하지 않는다.
- 판정·정렬·파싱·분할처럼 순수 함수로 뽑을 수 있는 로직은 먼저 뽑아 테스트로 고정한 뒤 화면을 얹는다(`computePagination`, `createRowJudge`, `extractWords`, `computeSearchMatches`, `upgradeBackup`, `createNewRelation`).
- 측정 함수처럼 DOM에 의존하는 입력은 인자로 주입해 가짜 측정으로 판정만 검사한다(`arrowNavigation`).

# 브라우저 검증 (playwright)

- **playwright는 저장소에 넣지 않는다.** 이 규모에 E2E를 유지하는 부담이 더 크다는 사용자 판단이다. 스크래치패드에 임시 설치해 쓰고, 브라우저 바이너리는 `~/.cache/ms-playwright`에 머신 전역으로 남아 재설치가 아니다.
- 개발서버(5173)에 붙거나, 배포 산출물은 `vite preview`에 붙는다. 오프라인·SW 검증은 preview에서 SW를 등록한 뒤 오프라인으로 전환한다.
- **프로필은 `launchPersistentContext`로 유지한다.** IndexedDB가 프로필에 있으므로 빈 컨텍스트를 쓰면 매번 데이터가 없다.
- **시드 데이터는 루트의 `corpus.json`(gitignore)을 설정 페이지에서 가져온다.** 파일의 `version`이 현재 `DB_VERSION`보다 낮으면 `upgradeBackup`이 승격하므로 그대로 가져와도 된다. 마이그레이션 자체를 검증하려면 이전 커밋 코드로 먼저 가져와 구버전 DB를 만든 뒤 새 코드로 연다. 새 관계 유형을 시험하려면 `corpus.json` 사본에 해당 레코드를 더한다.
- 마이그레이션 검증은 신규 생성, 직전 버전에서 올라오는 DB, 사고로 소모된 버전(인덱스 없는 DB)에서 올라오는 DB를 각각 연다.

## 함정

- **추천 목록이 열린 채 버튼을 클릭하면 click이 발화하지 않는다.** mousedown의 blur로 목록이 사라지며 버튼이 움직여 mouseup이 빗나간다. 토스트도 저장도 없는 거짓 음성이다. 다른 칸에 focus를 먼저 줘 목록을 닫고 클릭한다. [입력-포커스참고](./입력-포커스참고.md#클릭-소실-mousedown과-blur)
- **pico 버튼의 background transition(0.2초) 도중 스크린샷은 선택 상태가 틀려 보인다.** 잠시 기다리거나 `aria-pressed`를 읽는다.
- **다크 테마 스크린샷이 프리뷰에서 흰 카드로 보이는 착시**가 있다. 픽셀 샘플링으로 배경색을 읽는다.
- CSS 이론으로 두 번 틀린 기록이 있다. 레이아웃은 `getComputedStyle`·좌표 측정·`documentElement.scrollWidth === innerWidth`로 확인한다.

# 문서 검증

문서를 고친 뒤 아래를 돌려 0건인지 확인한다. `일지/`는 본문을 고치지 않으므로 링크 검사에서 제외한다.

- 깨진 링크:
  `cd llm && grep -rnoE '\]\([^)]+\.md(#[^)]*)?\)' --include=*.md --exclude-dir=일지 . | while IFS=: read -r f l link; do p=${link#*(}; p=${p%)}; p=${p%%#*}; [ -e "$(dirname "$f")/$p" ] || echo "$f:$l -> $p"; done`
- 코드 포인터 실존:
  `grep -rhoE 'packages/client/src/[A-Za-z0-9_./$-]+' llm --exclude-dir=일지 | sort -u | while read p; do [ -e "$p" ] || echo "$p"; done`
- 코드 사본: `grep -rn --include=*.md --exclude-dir=일지 -E '^```ts' llm`
- 분량: `wc -l llm/*.md llm/*/*.md | awk '$1>200'`
- 일지 보존: `ls llm/일지/20*.md | wc -l`과 `grep -c '^# 20' llm/일지/20*.md | grep -v ':1$'`
