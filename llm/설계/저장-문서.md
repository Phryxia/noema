# 문서의 경우

- 상위문서: [타입별 Store](./저장-스토어.md)
- `recentSentences`의 순환 큐 규약은 [문장 Store](./저장-문장.md)에 있다.

Store 이름은 `documents`. Key Path로 `documentId`를 가지며 자동 증가한다.
문서는 삽입, 수정, 삭제할 수 있다.

```ts
interface Document {
  // 임의의 문자열
  value: string
  // 고유값.
  // auto increment
  documentId: number
  // 추가된 시각
  createdAt: Date
  // 마지막으로 수정된 시각. 수정된 적이 없으면 undefined.
  modifiedAt?: Date
  // 출처
  source?: string
}
```

`value`를 수정해도 `documentId`는 바뀌지 않는다. 따라서 이 문서를 참조하는 `Relation`은 그대로 유효하다.

최근에 추가된 문서는 최대 4개까지 보관한다. Store 이름은 `recentDocuments`이며 `recentSentences`와 동일한 순환 큐다.

```ts
interface RecentDocument {
  documentId: number
  // 문서 초입의 64글자
  preview: string
  createdAt: Date
}
```

문서를 수정하면 해당 칸의 `preview`를 함께 고치고, 삭제하면 해당 칸을 `null`로 만든다.
