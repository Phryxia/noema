# 문장의 경우

- 상위문서: [타입별 Store](./저장-스토어.md)
- `recentWords`의 순환 큐 규약은 [단어 Store](./저장-단어.md)에 있다.

Store 이름은 `sentences`. Key Path로 `sentenceId`를 가지며 자동 증가한다.
문장은 삽입, 수정, 삭제할 수 있다.

```ts
interface Sentence {
  // 임의의 문자열
  value: string
  // 고유값.
  // auto increment
  sentenceId: number
  // 추가된 시각
  createdAt: Date
  // 마지막으로 수정된 시각. 수정된 적이 없으면 undefined.
  modifiedAt?: Date
}
```

`value`를 수정해도 `sentenceId`는 바뀌지 않는다. 따라서 이 문장을 참조하는 `Relation`은 그대로 유효하다.

최근에 추가된 문장은 최대 4개까지 보관한다. Store 이름은 `recentSentences`이며 `recentWords`와 동일한 순환 큐다.

- `0` ~ `3`: 추가된 문장 최대 4개에 대응되는 인덱스. 아직 존재하지 않거나 삭제됐으면 `null`.
- `next`: 최초에 `0`. `sentences`에 문장이 추가되면 `recentSentences[recentSentences.next]`에 `RecentSentence`를 쓴 뒤 1을 더하고 4로 나눈 나머지로 갱신한다.

```ts
interface RecentSentence {
  sentenceId: number
  // 문장 전체
  value: string
  createdAt: Date
}
```

`recentSentences`는 사본이므로 원본과 함께 갱신한다. 문장을 수정하면 해당 칸의 `value`를 함께 고치고, 삭제하면 해당 칸을 `null`로 만든다.
