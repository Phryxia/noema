# 대시보드

- 라우트: `/`

대시보드는 다음 요소로 구성된다.

# 입력 구역(`WriterSection`)

- 모드 선택(`WriterModeSelector`)
  - 라디오 버튼
  - `단어`, `문장`, `문서`
- 모드가 `단어`인 경우 `WordWriter`
- 모드가 `문장`인 경우 `SentenceWriter`
- 모드가 `문서`인 경우 `DocumentWriter`

# 최근에 추가된 것들 구역

## 최근에 추가된 단어(`RecentWords`)

- 최대 10개
- inline flex로 가장 최근에 추가된 순으로 나열
- 링크로 작성되며, 클릭 시 해당 단어 페이지로 이동한다.

## 최근에 추가된 문장(`RecentSentence`)

- 최대 4개
- 한 줄에 한 문장씩
- wrap으로 넘어가지 않도록 너무 길면 줄임표 (CSS로)
- 링크로 작성되며, 클릭 시 해당 문장 페이지로 이동한다.

## 최근에 추가된 문서(`RecentDocument`)

- 최대 4개
- 한 줄에 문서의 초입부분의 64글자
- wrap으로 넘어가지 않도록 너무 길면 줄임표 (CSS로)
- 링크로 작성되며, 클릭 시 해당 문서 페이지로 이동한다.

# 통계 구역(`Statistic)

다음의 통계들을 일목요연하게 볼 수 있다.

- 총 보유 단어 수
- 총 보유 문장 수
- 총 보유 문서 수
- 증가 추이 차트
  - 필터는 `<select>`와 `<option>` 활용
  - 시간 단위 필터(Filter)
    - 1시간 단위 (총 노출 24시간)
    - 1일 단위 (총 노출 28일)
    - 1주 단위 (총 노출 52주)
  - 모드 선택 필터
    - 변화량, 누적
  - 단어, 문장, 문서마다 차트를 하나씩 두고 한 행에 나란히 배치. 필터는 세 차트가 공유
    - 브라우저 폭이 좁으면 다음 줄로 밀림
  - 변화량 차트는 `증가`와 `삭제` 두 계열을 가짐. 누적 차트는 `보유` 한 계열
  - 차트 유형은 선 차트, 보간 방식 선형
  - 없는 값은 0으로 처리
