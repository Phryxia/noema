# 2026-07-30 탐색 페이지 단어 자동완성 클릭 동작 수정

## 문제

탐색 페이지의 단어 입력기에서 자동완성 항목을 누르면 해당 단어 페이지로 이동했다. 이 페이지에서는 폼 값을 그 단어로 채우는 것이 올바른 동작이다. 대시보드(WordWriter)의 자동완성은 기존대로 단어 페이지로 이동해야 한다.

## 해결

`WordSuggestion`에 선택적 `onSelect?: (word: string) => void` prop을 추가했다. `onSelect`가 있으면 항목을 `Link` 대신 button으로 렌더링해 `onSelect(word)`를 호출하고, 없으면 기존 `Link` 동작을 유지한다. 분기는 `WordSuggestionLabel` 컴포넌트로 분리했다. 탐색 쪽 `TextWriterField`는 `onSelect={onChange}`를 넘겨 폼 값을 채우고, `WordWriter`는 prop을 넘기지 않아 기존 동작이 유지된다. button은 CSS Module의 `.selectButton`으로 링크처럼 보이게 했다.
