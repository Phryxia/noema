# 2026-08-15 관계 짓기 배치 모드

## 문제

관계 짓기를 여러 조합 한꺼번에 넣고 싶은데, 단일 입력기로는 한 조합씩만 제출할 수 있었다.
결과 표는 관계 목록 표와 거의 같지만 참고 열이 결과(성공/중복/실패)로 바뀌고 행 색이 붙으며, 실패 행은 가리킬 관계가 없다.

## 해결

- `useBatchRelationEditor(editor)`가 배치 상태(스위치, textarea 세 개, 결과)를 단일 편집기 훅 바깥에서 들고, `RelationForm`은 `batch.isActive`일 때만 필드·제출·참고사항을 갈아 끼운다.
  스위치는 폼 밖(`RelationPage`)에 두어 단일 모드의 `focusFirstElement`가 스위치를 잡지 않게 했다.
- `submitBatchRelations`는 줄 파싱(`parseBatchLines`, 집합) → 단어 선확보 → `computeCartesianProduct` → 조합별 `findDuplicateTernaryRelationId` 후 `submitAnswer` 순서다.
  전부 중복이면 throw해서 전역 mutation 토스트 경로로 `모든 관계가 이미 있습니다`를 띄운다.
- `QnaTable`을 `QnaRowEntry`(`id: number | null`) 제네릭으로 일반화하고 `noteColumn`, `getRowTone`을 주입받게 했다. 표를 복제하지 않기 위해서다.
  `id`가 `null`인 행은 클릭 이동이 없다. 색은 pico가 `td`에 배경을 주므로 `.tone td`에 `color-mix`로 칠했다.
- `submitAnswer`가 relationId를 반환하게 했다(`createRelation`이 `add()` 키를 받음). 기존 호출부는 반환값을 쓰지 않는다.
