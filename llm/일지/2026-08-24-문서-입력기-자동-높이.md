# 2026-08-24 문서 입력기 자동 높이

## 문제

`DocumentWriter`의 본문 `textarea`가 `min-height: 256px` 고정에 수동 `resize: vertical`뿐이었다. 내용이 보이는 행 수를 넘으면 안쪽 스크롤이 생기고, 내용을 지워도 높이가 줄지 않았다. 요구는 행이 넘치면 늘리고, 줄어들면 마지막 행이 보일 만큼만 256px까지 줄이는 것, 가능하면 CSS만으로.

## 해결

`.textarea`에 `field-sizing: content` 한 줄을 더했다. `SentenceField`·`WordField`가 이미 쓰는 방식이라 JS 자동 높이 훅(`scrollHeight` 측정)은 만들지 않았다. `min-height`가 줄어들 때의 하한, `field-sizing`이 늘어날 때의 규칙이다.

`resize: vertical`은 남겼다. 사용자가 손으로 끌면 브라우저가 인라인 높이를 박아 그 뒤로는 자동 조정이 멈추는데, 수동 조절을 빼는 것보다 이쪽이 낫다고 봤다.

`height: max-content`는 기각했다. `textarea`는 치환 요소라 내재 높이가 내용이 아니라 `rows`로 정해지므로 `max-content`를 줘도 내용 길이를 반영하지 않는다. 내용을 내재 크기로 삼는 CSS 스위치는 `field-sizing: content`뿐이다.

미지원 브라우저(Firefox)는 지원하지 않기로 했다. 그쪽에서는 예전 동작(고정 256px + 수동 조절)으로 남으며 JS 폴백은 만들지 않는다.
