# 2026-08-15 개별 단어 페이지 삭제 버튼이 추천 목록에 가려짐

## 문제

개별 단어 페이지에서 삭제 버튼을 누르면 추천 목록이 뜨고 삭제는 되지 않았다. 한 번 더 눌러야 삭제됐다.
`WordEditor`가 `useSuggestionFocus`의 `handleFocus`/`handleBlur`를 `form` 전체에 걸어 두어, mousedown으로 삭제 버튼이 포커스되는 순간 `isFocused`가 참이 되고 절대 위치의 `WordSuggestion`이 버튼 위를 덮었다. mouseup이 추천 목록 위에서 일어나 버튼의 click이 성립하지 않았다.

## 해결

`WordField`와 `WordSuggestion`만 감싸는 `div`에 `rootRef`/`onFocus`/`onBlur`를 옮기고 `WriterActions`는 그 바깥(폼 안)에 두었다.
버튼이 포커스되면 래퍼 기준 blur가 발생해 추천 목록이 닫힌다. 화살표로 추천 목록을 오가는 흐름은 래퍼 안에서 그대로 유지된다.
