# 개요

재사용 컴포넌트의 사양을 서술한다.

- 상위문서: [화면](./화면.md)
- 이 컴포넌트들을 배치하는 페이지는 [페이지 사양](./화면-페이지.md)에 있다.
- 컴포넌트가 읽고 쓰는 데이터의 스키마는 [타입별 Store](../설계/저장-스토어.md)에 있다.

# 몇몇 재사용될 컴포넌트들

- 전각 문자의 폭이 일정해야 한다.
- 반각 문자는 전각 문자의 절반이어야 한다.
- 즉 모든 컴포넌트의 폰트는 고정폭 문자여야 한다.

## 단어 입력기(`WordWriter`)

- 개행이 불가능한 텍스트 `input`와 저장버튼
- 저장 버튼을 누르거나 `Enter`를 치면 저장된다.
- 입력된 내용이 이미 존재하는 단어면 저장 버튼이 비활성화되고 `Enter`도 먹지 않는다.
  - 앞뒤 공백은 다듬지 않으므로 `사과`와 `사과 `는 서로 다른 단어다.
- 스페이스 만으로도 입력할 수 있는데, 이것이 눈에 보이도록 하라.
  - 입력하는 것을 도중에 방해하면 안된다.
  - 에코용 오버레이 컴포넌트에 `␣`(U+2423)를 겹쳐 보여주는 것을 추천한다.
- 입력된 내용을 기반으로 해당 접두사로 존재하는 단어들을 16개 정도 입력기 밑에 띄운다.
  - 자세한 것은 단어 추천기(`WordSuggestion`) 참고
- 수정 가능 여부를 `prop`으로 받음. 수정 불가인 경우 읽기 전용.

## 출처 입력기(`SourceField`)

- 출처를 적는 한 줄짜리 `input`. 문장/문서 입력기가 함께 쓴다.
- 선택적으로 적을 수 있다.
  - 빈 값이면 수정/저장 시 `undefined`이 되어야 한다.
- 수정 가능 여부를 `prop`으로 받음. 수정 불가인 경우 읽기 전용.

## 문장 입력기(`SentenceWriter`)

- 개행이 가능한 `textarea`, 출처 입력기와 저장버튼
- 저장 버튼을 누르거나 `Ctrl + Enter`를 치면 저장된다.
- 스페이스와 탭만으로도 입력할 수 있으며, 단어 입력기처럼 눈에 보이게 해라.
  - 탭용 문자로 `→`를 겹쳐 보여주는 것을 추천한다.
  - `Tab`을 가로채 탭 문자를 넣는다. 저장이 `Ctrl + Enter`이므로 다음 요소로 갈 `Tab`이 필요 없다.
  - `Shift + Tab`은 가로채지 않는다. 포커스를 뒤로 뺄 길은 남겨둔다.
- 수정 가능 여부를 `prop`으로 받음. 수정 불가인 경우 읽기 전용.
- 높이는 조정 가능해야 함
- 최소 높이 256px

## 문서 입력기(`DocumentWriter`)

- 개행이 가능한 `textarea`, 출처 입력기와 저장버튼
- 저장 버튼을 누르거나 `Ctrl + Enter`를 치면 저장된다.
- 텍스트 파일을 드래그할 경우 그 내용물이 폼에 적힌다.
  - 출처에 파일 이름이 기본값으로 세팅된다. 물론 수정할 수 있다.
- 단어/문장 입력기와 다르게 탭은 보여주지 않아도 된다. 그냥 자연스럽게 놔둔다.
  - 다만 `Tab` 가로채기는 문장 입력기와 동일하게 한다.
- 수정 가능 여부를 `prop`으로 받음. 수정 불가인 경우 읽기 전용.
- 높이는 조정 가능해야 함
- 최소 높이 256px

## 메타 정보 표시기(`MetaFields`)

- `{ label, value }` 쌍의 배열을 `prop`으로 받아 그리드로 나열하는 읽기 전용 폼
- 값의 출처를 알지 못한다. 단어/문장/문서 어느 페이지든 같은 컴포넌트를 쓴다.
- `value`의 타입별 표기
  - `Date`는 한국 로캘의 날짜+시각
  - `undefined`는 `없음`
  - 나머지는 문자열 그대로
- 값은 선택해 복사할 수 있어야 한다.
- 항목 수와 화면 폭에 따라 열 수가 자동으로 접힌다.

## 단어 추천기(`WordSuggestion`)

- 단어 추천기는 입력 `prop` 대해, Trie에서 `prop.keyword`와 접두사가 일치하는 `Lexis`들을 최대 `prop.n`개 나열한다.
  - 한 줄에 하나씩 좌측정렬하여 나열한다
  - 제일 오른쪽에 삭제 버튼 (x), 누르면 삭제됨
    - 삭제 시 해당 단어를 참조하던 `Relation`을 전부 제거함
    - 최근에 추가된 단어에 해당 단어 있으면 삭제
- 이들은 개별 단어 페이지로의 `a` 태그를 갖는다.
- 100ms throttle을 걸어서 수행한다.
