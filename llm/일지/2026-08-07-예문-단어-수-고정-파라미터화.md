# 2026-08-07 예문 단어 수 고정 파라미터화

## 문제

예문 만들기(`WordsUsage`)의 단어 수가 1~3개 랜덤이라 사용자가 제어할 수 없었다.

## 해결

`pickQuestion`에 `usageWordCount` 인자를 추가해 랜덤을 제거하고,
탐색 페이지 출제기에 숫자 입력 `UsageWordCountControl`(기본 1, 1 이상 정수, 상한 없음)을 붙였다.
값은 `usageWordCountStorage`로 localStorage(`explore/usageWordCount`)에 저장한다.

"다음 문제부터 적용"은 유형 체크박스와 같은 방식으로, `useExplore`에
`appliedUsageWordCount` ref를 두고 `draw` 시점에만 갱신한다.
현재 pick이 `ok`가 아니면(단어 부족 등) 값 변경 즉시 재출제한다.

상한 제거로 3개 초과 단어의 관계가 생길 수 있어, `loadRelationSnapshot`의
`resizeWords` 목표 길이를 `Math.max(values.length, spec.count)`로 바꿔
관계 수정 화면의 잘림을 막았다. `MAX_USAGE_WORD_COUNT`는 알려주기 입력칸 수(3) 용도만
남아 `relation/consts.ts`의 리터럴로 흡수했다.
임베딩 실험은 `LabQuestionTypes`에 `WordsUsage`가 없어 영향이 없다.
