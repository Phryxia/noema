# 2026-07-30 단어 완성제안 포커스 연동

## 문제

단어 입력기의 완성제안이 포커스와 무관하게 항상 노출됐다. 포커스가 풀리면 숨기고, 다시 잡히면 노출해야 한다. 모든 사용처(WordWriter, TextWriterField) 공통 적용.

## 해결

`WordField`에 `onFocus`/`onBlur` prop을 추가하고, 두 부모(`WordWriter`, `TextWriterField`)가 `isFocused` 상태를 들고 `{isFocused && <WordSuggestion />}`로 조건부 렌더링한다.

핵심 함정: 제안 항목 클릭 시 input의 blur가 click보다 먼저 발생해, 제안이 언마운트되며 클릭이 소실된다. `WordSuggestion` 루트 `article`에 `onMouseDown={(event) => event.preventDefault()}`를 걸어 클릭 시 input이 포커스를 잃지 않게 했다. Safari는 button 클릭 시 포커스를 옮기지 않아 `:focus-within` CSS 방식은 깨지므로, mousedown preventDefault 방식이 크로스 브라우저에서 안전하다.
