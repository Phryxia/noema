# 2026-08-04 임베딩 실험 입력 라벨과 온도 조절

## 문제

임베딩 실험 페이지의 `dMin`, `dMax`, `dResolution` 입력이 placeholder와 `aria-label`에만 의존해, 값을 채우면 무엇을 뜻하는지 알 수 없었다. 또 Gumbel-max 온도 `τ`가 상수 `SOFTMAX_TEMPERATURE = 1`로 박혀 있어 출제 다양성을 화면에서 시험할 수 없었다.

## 해결

세 입력에 각각 `최소 차원`, `최대 차원`, `탐색 개수` 라벨을 붙이고 `.grid`로 배치했다. 버튼은 그리드 밖으로 뺐다.

온도는 상수를 `DEFAULT_SOFTMAX_TEMPERATURE = 2`로 바꿔 초기값으로만 쓰고, `proposePair(model, trie, labeledPairs, temperature)`의 인자로 내렸다. 실험 학습(`runExperiment`)은 온도를 쓰지 않고 출제(`pickLabQuestion`)만 쓰므로, 실험 시작 파라미터(`DimRange`)에 넣지 않고 `useEmbeddingLab`의 `temperatureRef`에 즉시 반영해 다음 출제부터 적용되게 했다. 입력은 `min={0}`이며, 빈 값·음수·`NaN`은 ref를 갱신하지 않아 직전 유효값이 유지된다.
