# 2026-07-21 화면.md 재분리

## 문제

[화면 사양](../기획/화면.md)이 122줄로 분할 규칙(200줄) 대상은 아니었으나, 사용자가 더 쪼개라고 요청했다.

## 해결

내용을 바꾸지 않고 문서의 두 절을 그대로 둘로 나눴다. 경계는 원래부터 있던 최상위 헤딩이다.

- [재사용 컴포넌트](../기획/화면-컴포넌트.md): 고정폭 폰트 규칙과 입력기/추천기 4종
- [페이지 사양](../기획/화면-페이지.md): 메인과 개별 단어/문장/문서 페이지

`기획.md`의 허브 목록은 두 새 문서를 직접 가리키도록 바꿨다. 중간 허브를 두지 않는 기존 결정과 같은 이유다.
다만 `화면.md`는 지우지 않고 두 문서를 가리키는 이정표로 남겼다. 이 history를 포함해 옛 경로로 걸린 링크가 있기 때문이다.

이후 사용자 피드백에 따라, 기획 하위 네 문서의 개요에서 "어디에서 분리됐다"는 역사 서술을 전부 지우고
상위문서/하위문서 링크만 남기는 형식으로 통일했다. 디렉토리 구조와 링크가 유래를 이미 함의하기 때문이다.
역사는 history에만 적는다.

원본에 있던 두 가지 이상한 점은 수정하지 않고 그대로 옮겼다.

- 메인 페이지의 `WriterSection`에서 `DocumentWriter`의 조건이 `문장`으로 적혀 있던 오타는 사용자가 직접 수정했다.
- 개별 단어 페이지의 마지막 항목 "값은 수정돼 있는데 수정 버튼을 누르지 않은 경우"가 뒷내용 없이 끊겨 있다. 사용자 확인이 필요하다.
