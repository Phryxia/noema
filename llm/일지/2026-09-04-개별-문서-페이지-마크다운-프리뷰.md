# 2026-09-04 개별 문서 페이지 마크다운 프리뷰

## 문제

마크다운 프리뷰가 다이어리 페이지에만 있었다. 개별 문서 페이지(`/document/$documentId`)에서도 노출하라는 요청.

## 해결

- `DocumentWriter`가 이미 `renderPreview` prop을 갖고 있어([배치 수정](./2026-09-04-다이어리-프리뷰-배치-수정.md)) 페이지에서 prop 한 줄을 넘기는 것으로 끝났다. 수정 모드에서도 initial draft가 문서 본문이라 진입 즉시 저장된 내용이 렌더된다.
- `MarkdownPreview`가 다이어리와 문서 두 관심사에서 쓰이게 되어 `diary/`에서 `shared/`로 `mv`했다. 관심사 하나에 종속되지 않는 공용 부품의 자리다.
- playwright로 `/document/1` 진입: 프리뷰가 본문 옆 같은 높이(top 693, 각 570px)에 저장된 본문을 렌더, 본문 수정 시 즉시 갱신(KaTeX 포함), 수정 버튼 활성화, 가로 스크롤 없음.
