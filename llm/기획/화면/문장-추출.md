# 문장 추출

- 상위문서: [페이지](../화면-페이지.md)의 _개별 문서_ 항
- 저장 규약은 [문서-문장 관계 Store](../../설계/저장-관계-문서문장.md)에 있다.
- 구현은 `packages/client/src/extraction/`에 있다.

문서 본문을 문장 카드로 잘라 사람이 다듬은 뒤 한 번에 제출한다. 제출하면 문장들이 삽입되고
(문서, 문장) 1쌍당 1개의 `DocumentToSentence` 관계가 만들어진다.

## 진입

- 개별 문서 페이지의 `연결된 문장` 구역은 이 문서를 가리키는 관계가 0건일 때만 `문장 추출` 버튼을 보인다.
- 버튼을 누르면 같은 구역이 `문장 추출` 편집기로 바뀐다. 제출이 끝나 관계가 생기면 구역은 표로 바뀐다.
- 제출하지 않고 이탈하면 모든 수정은 사라진다. 이탈 질의도 없다.

## 최초 분할

본문의 `\r\n`/`\r`을 `\n`으로 정규화한 뒤 `/.*[.!?"']?(\n\s*|$)/g`로 자르고, 각 조각을 `trim`하고 빈 문자열을 버린다(`extractSentences`).
`.`가 `\r`을 줄바꿈으로 취급해 CRLF 문서의 본문을 통째로 잃기 때문에 정규화가 앞선다.
`[.!?"']?`가 선택이라 실질적으로는 줄 단위 분할이며, 잘리면 안 되는 것도 잘리므로 아래의 병합·분할로 사람이 고친다.

## 문장 카드

- 헤더 아래에 병합/분할/삭제 조작법을 `small`로 세 줄 적는다.
- 카드 하나가 문장 하나. `SentenceField`를 `rows=1`(`compact`)으로 그린다. 탭·개행 입력, 공백 시각화가 대시보드 문장 입력기와 같다.
  높이는 CSS `field-sizing: content`로 내용에 맞춰 늘어난다(1줄 최소, 수동 리사이즈 없음). JS 측정은 쓰지 않는다.
- 카드 사이에 버튼은 없다. 병합은 키보드로만 한다.
- 맨 아래에 `제출` 버튼. `trim`이 비어 있지 않은 카드가 하나라도 있어야 활성.

### 상태

문서가 길 수 있으므로 카드 목록은 불변 연결 리스트 `{ headId, nodes: Map<id, { id, value, prevId, nextId }>, nextId }`다(`sentenceCardList.ts`).
병합·분할·삭제는 포인터만 고치고, `id`는 발급 후 바뀌지 않아 React key와 포커스 대상으로 쓴다.
`SentenceCard`는 `memo`이며 훅이 넘기는 핸들러는 모두 안정적이라 값이 바뀐 카드만 다시 그린다.

### 병합

- 카드가 비어 있지 않고 캐럿이 맨 앞(선택 없음)인 상태에서 Backspace를 **뗄 때** 앞 카드 값 뒤에 **구분자 없이** 이어 붙이고 이 카드를 지운다.
  앞 카드로 포커스, 캐럿은 접합점. 첫 카드면 아무 일도 없다.
- 카드 사이 `병합` 버튼은 2026-08-16에 두었다가 보기 좋지 않아 같은 날 지웠다.
- keydown에서 조건을 판정해 플래그로 두고 keyup에서 실행한다(`WordField`와 같은 패턴). IME 조합 중(`isComposing`)이면 무시한다.

### 분할

- 카드 값이 바뀔 때 `\n\n\n`이 들어 있으면 그것을 경계로 쪼개고 각 조각을 `trim`하고 빈 조각을 버린다(`splitByTripleNewline`).
  - 조각 2개 이상: 첫 조각이 현재 카드, 나머지는 새 카드로 뒤에 끼운다. 두 번째 조각 카드의 맨 앞으로 포커스.
  - 조각 1개(끝에서 Enter 3번 등): 현재 카드 값만 그 조각으로 바꾼다. 새 카드는 만들지 않는다.
  - 조각 0개: 빈 카드가 된다.
- 어떤 카드도 `\n\n\n`을 품은 채 남지 않으므로 "포커스 시점 값과 비교"는 현재 값의 `includes('\n\n\n')`과 같다.
- 쪼개는 데 쓴 개행은 어느 조각에도 남지 않는다.

### 카드 삭제

- 값이 빈 카드에서 Backspace를 뗄 때 카드를 지운다. 앞 카드 끝으로 포커스, 앞이 없으면 뒤 카드 앞으로.
- 마지막 글자를 지우는 Backspace는 keydown 시점 값이 비어 있지 않아 삭제로 이어지지 않는다. 한 번 더 눌러야 한다.

## 제출

- `trim`이 빈 카드는 제외하고 나머지 값은 원문 그대로(앞뒤 공백 유지) 문장이 된다.
- 문장과 관계는 하나의 `readwrite` 트랜잭션(`sentences`, `recentSentences`, `relations`)에서 만들어지며 `createdAt`은 클릭 시점 하나를 모두가 공유한다.
- 문장 `source`는 `Extracted via NOEMA system extraction, did=<documentId>`.
- 성공 시 `문장 n개를 저장했습니다` 토스트, 관계·문장·통계 쿼리 무효화. `연결된 문장` 구역이 표로 바뀐다.
