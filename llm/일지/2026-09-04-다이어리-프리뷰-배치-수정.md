# 2026-09-04 다이어리 프리뷰 배치 수정

## 문제

[다이어리 페이지](./2026-09-04-다이어리-페이지.md)의 첫 구현은 페이지가 `DocumentWriter` 전체와 프리뷰를 2열 grid로 나눴다. 프리뷰가 제목·출처 칸 옆까지 차지해 보기 나쁘다는 사용자 지적이 있었다. 제목·출처는 전체 폭으로 두고, 본문 `textarea` 옆에만 프리뷰를 나란히 놓아야 했다.

## 해결

- 프리뷰가 본문 옆에 오려면 폼 내부 구조에 들어가야 한다. `onValueChange`로 값을 페이지에 올려 페이지가 배치하는 구조로는 불가능해 기각하고, `DocumentWriter`에 `renderPreview?: (value: string) => ReactNode` prop을 만들었다. prop이 있으면 `textarea`와 `renderPreview(draft.value)`를 `.bodyRow`(2열 grid, 768px 이하 1열, 자식 `min-width: 0`)로 감싸고, 없으면 기존 그대로다. draft가 폼 안에 있으므로 페이지의 상태·effect(`onValueChange` + `useState`)가 통째로 사라져 `DiaryPage`가 상태 없는 컴포넌트가 됐다.
- `onValueChange` prop과 `useEffect`는 제거했다. 두 prop을 다 두는 것은 같은 목적의 중복이다.
- playwright 실측: 제목·출처 폭 1160px, textarea·프리뷰가 top 465로 같고 각 570px, 가로 스크롤 없음.

- 미사용이 된 `diary/DiaryPage.module.css`는 사용자 허가를 받아 삭제했다.
