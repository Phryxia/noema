# 단어

Trie로 저장되는 짧은 문자열. 대시보드의 단어 입력기, 추천기, `/word/$word` 개별 단어 페이지, 최근 단어 순환 큐.

## 코드

- 디렉토리: `packages/client/src/word/`
- 타입: `word/types.ts`(`TrieNode`, `Lexis`, `RecentWord`), 상수·쿼리 키·트랜잭션 범위: `word/consts.ts`
- 서비스: `word/word.service.ts`(`createWord`, `upsertWord`, `deleteWord`, `getWordNodeId`, `getWordNode`, `getWordsByPrefix`, `getRecentWords`), 트랜잭션 스코프 헬퍼: `word/wordTx.ts`
- 수정·삭제: `word/updateWord.ts`, `word/deleteWordReplacingReferences.ts`, `word/useGuardedWordDeletion.ts`, 참조 교체는 `relation/replaceWordReferences.ts`·`relation/hasWordReferences.ts`
- 조회 유틸: `word/getWordValues.ts`(nodeId -> 문자열 배치 복원), `word/getRandomWords.ts`, `word/getWordCount.ts`, `word/RecentWordSource.ts`(최근 목록용)
- 컴포넌트: `WordField`(입력 원자), `WordWriter`(대시보드 저장 폼), `WordSuggestion`, `WordEditor`(개별 페이지 수정·삭제), `WordReplaceDialog`, `WordRelations`, `RecentWords`, `useSuggestionFocus.ts`
- 페이지: `routes/word.$word.tsx`(+ `s2w/WordSentences`, `tag/WordTags`)
- 무효화: `word/utils.ts`(`invalidateWordQueries`, `invalidateWordAndQnaQueries`)
- 미사용: `word/getAllWordNodeIds.ts`(임베딩 실험 제거 후 호출처 없음. llm 밖 삭제는 허가 필요)

## 사양

- 단어는 중복될 수 없고 유니크 키로 쓴다. 대소문자는 다른 단어, 기호도 단어, 앞뒤 공백을 다듬지 않으므로 `사과`와 `사과 `는 다른 단어다. 스페이스만으로도 단어를 만들 수 있고, 이것이 눈에 보여야 한다(공백 에코).
- 저장: `wordNodes`(Key Path `nodeId`, 루트 0)에 한 글자 한 노드로 삽입한다. 리프의 `createdAt`이 `isEnd`를 겸하고, 개명된 적이 있을 때만 `modifiedAt`이 있다. `wordMeta`가 `trieNodeSize`(루트 포함), `wordSize`, `nextNodeId`를 갖는다. `createdAt` 인덱스가 단어 노드만 담아 최근 목록과 출제 모집단이 된다.
- 문자열 -> nodeId는 루트에서 `children`을 따라 L+1번 `get`, nodeId -> 문자열은 `parentNodeId`를 거슬러 오른다. 접두사 나열은 접두 노드에서 DFS. 라우트가 `/word/$word`라 페이지 진입마다 이 변환이 일어난다.
- 최근 단어: `recentWords` 순환 큐 10칸 + `next`. 읽을 때는 `next - 1`부터 역순, `null`/`undefined` 칸은 건너뛴다.
- `WordWriter`: `input` + 저장 버튼, Enter 또는 버튼으로 저장. 이미 있는 단어면 버튼 비활성·Enter 무시. 존재 확인이 끝나기 전(`isChecking`)에도 잠근다. 아래에 `WordSuggestion` 16개.
- `WordSuggestion`: 접두사 일치 단어를 한 줄에 하나, 개별 단어 페이지 링크 또는 `onSelect` 버튼. 오른쪽 x 버튼은 참조 관계가 없으면 즉시 삭제, 있으면 `WordReplaceDialog`. 100ms throttle. `isVisible`로 숨고 언마운트되지 않는다.
- 개별 단어 페이지: `WordEditor`(수정·삭제), `MetaFields`(`nodeId`, `parentNodeId`, `createdAt`, `modifiedAt`), `연관 관계`(`WordRelations`: 관계 검색의 정확히 일치 결과와 같은 `QnaTable`, `포함 유형` 필터는 문제 유형 10개, URL 미사용, 10분 캐시), `단어를 추출한 문장`(`WordSentences`, [단어-추출](./단어-추출.md)), `태그된 문장/문서`(`WordTags`, [태그](./태그.md)). 뒤의 두 구역은 비어 있으면 숨긴다.
- 수정: 수정 사항이 있을 때만 활성. 관계 영향 질의 후 반영하고 결과 단어 페이지로 이동한다(`nodeId`가 바뀐다). 결과가 이미 있는 단어면 병합 여부를 confirm으로 묻는다. 미저장 수정 이탈 질의가 적용된다([입력기](./입력기.md)).
- 삭제: 참조 관계가 없으면 삭제 후 메인으로. 있으면 `WordReplaceDialog`로 취소 또는 대체 단어를 받는다. 대체 단어가 없으면 같은 트랜잭션에서 생성한다. 최근 단어 큐에서도 지운다.

## 결정 근거와 제약

- **개명은 새 nodeId 발급 + 참조 교체, 삭제는 참조 실교체.** tombstone 폐기 근거와 삽입을 제거보다 먼저 하는 이유는 [저장개발참고](../참고/저장개발참고.md#단어-trie).
- 개명 절차: 새 경로 삽입(리프에 원본 `createdAt` 이전, `modifiedAt` 기록) -> 원본 노드를 삭제 규칙대로 제거 -> `relations`의 단어 참조 교체 -> `recentWords` 슬롯 제자리 수정. 단어 수 순변화 0이라 통계 미기록. 병합이면 새 삽입 없이 참조 대상만 기존 nodeId이고, `recentWords`에 둘 다 있으면 원본 슬롯을 `null`로 비우며, 통계 감소를 기록한다. 같은 값 수정은 no-op.
- 삭제 규칙: 리프의 `createdAt`/`modifiedAt` 제거, `wordSize` 감소 -> `createdAt`도 `children`도 없는 노드를 부모에서 떼고 제거하며 `trieNodeSize` 감소 -> 부모로 반복, 루트는 제거하지 않는다(가지치기).
- `wordMeta` 초기값은 `trieNodeSize=1`, `wordSize=0`, `nextNodeId=1`. 루트가 최초에 존재하고 삭제 규칙이 루트를 제거하지 않으므로 루트를 세는 쪽이 정합적이다(2026-07-21 사양 충돌 정정).
- `createWord`는 기존 단어면 no-op으로 같은 nodeId를 준다. 대시보드는 이 사실을 UI가 알아야 하므로 `isExisting`으로 막고, 탐색은 기존 단어로 답하는 것이 정상이라 막지 않는다. 그래서 중복 검사와 저장 버튼은 `WordField`가 아니라 `WordWriter`에 있다.
- `replaceWordReferences`는 7개 단어 인덱스로 대상을 모아 `relationId` Map으로 중복 제거 후 한 번씩만 `put`한다. 병합·교체로 생기는 퇴화 관계(`word1Id === word2Id`)는 남긴다.
- nodeId -> 문자열 복원은 조상 문자열 `Map`으로 메모이즈한다. 접두사를 공유하는 단어가 나란히 있을수록 덜 읽는다.
- 개별 단어 페이지는 `key={word}`로 개명 이동 시 페이징 상태를 초기화한다.

## 알려진 함정

- 추천 목록 클릭 소실, 삭제 버튼이 추천 목록에 가려짐, 포커스 범위: [입력-포커스참고](../참고/입력-포커스참고.md#클릭-소실-mousedown과-blur).
- `WORD_NODE_ID_QUERY_KEY` 등 단어 쿼리 키는 반드시 `invalidateWordQueries`로 무효화한다. 삭제한 단어를 다시 저장하지 못한 전례가 있다.
- 존재 판정은 `typeof existingNodeId === 'number'`다. 미조회 `undefined`, 미존재 `null`, 그리고 `0`이 truthy 검사에 걸린다.
- 단어 페이지의 미저장 수정 + `useBlocker` 이탈 승인은 전역 개명을 실행한다. 병합 confirm이 관계 화면으로 전환되는 시점에 떠서 관계 수정처럼 보인 사고가 있었다.
