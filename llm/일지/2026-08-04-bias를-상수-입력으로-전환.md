# 2026-08-04 bias를 상수 입력으로 전환

## 문제

수동 튜닝을 없애려고 bias를 학습 파라미터(`{mu, varr}`)로 바꿨으나 성능이 나빴다.
상수로 되돌리되, 값을 화면에서 조절할 수 있어야 했다.

## 해결

`EmbeddingModel.bias`를 `number` 상수로 바꾸고 `updateModel`의 bias 갱신식을 제거했다.
`ExperimentControls`의 차원설정 grid 행에 바이어스 입력(기본 `DEFAULT_BIAS = -3`)을 추가하고,
`onStart -> startExperiment -> runExperiment -> createModel(d, bias)`로 전달한다.
빈 문자열은 `Number('') === 0`으로 새는 것을 막기 위해 `!!bias.trim() && Number.isFinite()`로 시작 버튼을 잠근다.
저장 스키마는 bias 직렬화 형태가 바뀌어 version 4로 올렸고, 구버전(3)은 폐기된다.
