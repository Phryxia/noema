# 개요

상위문서: [history](../history.md)

코드를 만들거나 고친 작업의 기록이다. 다루는 계층에 따라 두 문서로 나뉘어 있다.

- [저장 구현 기록](./구현/저장.md): Indexed DB 스키마, 마이그레이션, 서비스 계층.
  Store가 왜 이렇게 생겼는지, 트랜잭션을 어떻게 묶었는지 찾을 때 본다.
- [화면 구현 기록](./구현/화면.md): React 컴포넌트, JSX 구조, CSS.
  컴포넌트를 왜 이렇게 쪼갰는지, pico와 어떤 스타일 충돌이 있었는지 찾을 때 본다.

새 기록은 성격에 맞는 문서의 개요 바로 아래에 최신순으로 추가하고, 그 문서 개요의 목차에도 한 줄을 더한다.
한 작업이 양쪽에 걸치면 무엇이 문제였는지를 기준으로 한쪽에만 적는다.
