# 개요

이 문서는 [탐색](./탐색.md) 문제 추천 알고리즘 개선을 위해, 임베딩 실험 모드를 추가하는 기획이다.

# 동기

단어의 이진 유사도 (탐색 문서 참고) 는 두 단어가 얼마나 같은 방향의 의미를 갖는지 물어보는 문제다.
그러나 문제는 무작위로 두 단어를 선택 시, 높은 확률로 항상 무관계(0)가 나온다.

이를 해결하기 위해, 임의의 단어가 주어졌을 때, 무관계가 아닐 확률을 추정하는 온라인 학습 모델을 *출제기*로 채택하려 한다.
이 출제기 또한 하나의 (설명은 불가능한) 지식 모델로 기능한다.

이를 위해선 임베딩 벡터의 차원을 결정해야 하는데, 한 번 임베딩 차원을 결정하면 현실적으로 바꾸기가 어려워진다.
왜냐하면 DB의 벡터들을 다 지우고 처음부터 학습로그를 전부 돌려야 하기 때문이다.

그래서 임베딩 벡터를 DB에 적재하지 않고 메모리 상에서만 실험을 하여, 기존에 응답했던 로그로 학습을 진행한 뒤,
사용자가 해당 모델을 쓰면서 계속해서 로그를 적재한다.

이렇게 학습된 모델은 실험된 모든 차원에 대해 Local Storage에 저장한다.
모델 리포트(궤적)는 메모리에만 존재한다. 페이지 재진입 시 모델 목록은 복원되지만 궤적은 사라지며,
이후 사용자가 응답할 때마다 점이 다시 추가된다. 재진입 시 선택은 `no model`로 초기화된다.

기존 탐색 페이지에는 어떤 동작 영향도 없어야 한다.
단, 아래의 무응답 제출 허용은 예외로, 기존 탐색 페이지에도 적용된다.

## 무응답 제출 (스펙 변경)

이분 공통점/차이점 문제는 예문 만들기(`WordsUsage`)처럼 무응답(빈 문자열) 제출을 허용한다.
이 경우 관계의 `answer`는 `null`로 DB에 정상 적재된다. 건너뛰기는 기존대로 아무것도 저장하지 않는다.
실험장의 무관계(0) 신호는 건너뛰기가 아니라 이 무응답 제출이다.

# 학습 알고리즘

이 온라인 학습 알고리즘은 간단한 Online Bayesian Learning으로, 임베딩 벡터를 단일 모드 타원체 확률 분포로 가정한다.

- 모델은 두 단어 `x`, `y`가 무관계가 아닌 답을 줄 확률 $p(x, y)$ 이다.
- 사전분포는 $p(x) * p(y)$ 로 가정한다.
- 두 임베딩 벡터의 내적의 시그모이드로 likelihood를 가정한다.
- `bias`는 학습하지 않는 고정 상수 `-2`다. 무작위 쌍은 대부분 무관계이므로 낮은 사전확률을 반영한다.
- `x`는 항상 균등 랜덤으로 고르고, `y`는 `x`에 대해 Prior를 최대로 만드는 것을 선택한다.
  - 이때 `y`의 임베딩 분포에서 샘플링을 하여 불확실성을 반영한다.
- 사용자의 응답으로 사후분포를 교정한다.

Pseudocode는 다음과 같다.

```ts
type Word = { mu: number[]; varr: number[] }

const getWord = (w: string): Word => {
  const found = state.get(w)
  if (found) return found
  const fresh = { mu: randomInit(d), varr: ones(d) }
  state.set(w, fresh)
  return fresh
}

const sample = (w: Word): number[] => w.mu.map((m, i) => m + gaussian() * Math.sqrt(w.varr[i]))

const proposePair = (): [string, string] => {
  const u = uniformPick(allWords)
  const zu = sample(getWord(u))
  const v = argmax(unlabeled(u), (c) => dot(zu, sample(getWord(c))) + bias)
  return [u, v]
}

const update = (u: string, v: string, y: number) => {
  const target = y === 0 ? 0 : 1
  const wu = getWord(u)
  const wv = getWord(v)
  const p = sigmoid(dot(wu.mu, wv.mu) + bias)
  const err = target - p
  for (let i = 0; i < d; i++) {
    wu.mu[i] += wu.varr[i] * err * wv.mu[i]
    wv.mu[i] += wv.varr[i] * err * wu.mu[i]
    wu.varr[i] /= 1 + wu.varr[i] * wv.mu[i] ** 2 * p * (1 - p)
    wv.varr[i] /= 1 + wv.varr[i] * wu.mu[i] ** 2 * p * (1 - p)
  }
}
```

# 기능

라우팅 `/lab/embedding` 페이지에 기존 탐색과 거의 유사한 페이지를 갖춘다.

이 페이지는 기본적으로 탐색과 동일한 기능을 하나, 출제 유형 집합이 `{ 이분 유사도, 이분 공통점, 이분 차이점 }`로 고정된다.
따라서 체크박스가 존재하지 않는다.

이후 문제/응답 컴포넌트가 주어진다. 이들은 기존 탐색 페이지와 동일하게 질의응답을 적재한다.

그 아래에는 차원 파라미터 탐색범위를 설정하는 2개의 input요소(`dMin`, `dMax`), 탐색수(`dResolution` < `dMax - dMin + 1`), 실험 시작 버튼이 있다.

실험 시작 버튼을 클릭하면 프로그레스 바가 생기고, `dMin`부터 `dMax`의 범위(inclusive)를 `dResolution`개 시험해본다.
즉, `dResolution` 개의 모델이 만들어진다. 이 모델들은 DB에 들어있는 이항 관계들을 1개씩 먹이면서 학습한다.

## Training/Test 분할

온라인 학습이므로 고정 비율의 사전 분할 대신, 학습 전후로 매 스텝마다 들어오는 데이터를 확률적으로 나눈다.

- 0.8의 확률로 training set에 속한다. 이 경우 임베딩을 갱신하고 training accuracy를 갱신한다.
- 0.2의 확률로 test set에 속한다. 이 경우 임베딩을 갱신하지 않고 validation accuracy를 갱신한다.

accuracy는 그 시점까지 해당 set에 쌓인 전체에 대한 예측 성공률이며, 갱신되지 않은 쪽은 직전 값을 유지한다.
실험 시작 시에는 전체 로그를 재생하며 스텝마다 이 분할을 적용하고, 분할은 모든 차원의 모델이 공유한다.
온라인으로 들어오는 응답은 도착 시점에 분할되며, test로 분류된 응답은 어떤 모델도 학습하지 않는다.
분할은 메모리에만 존재한다.

이때 유형별로 다음과 같은 강화학습 신호를 제공한다.

- 이분 유사도인 경우, 0이 아니면 1, 0이면 0
- 공통점과 차이점인 경우, 무응답(`answer: null`)이면 0, 답이 있으면 1
  (무응답 제출 허용 이전의 데이터는 전부 1이다)

모델이 하나씩 학습 완료될 때 마다 프로그레스 바 아래에 `no model`, `d=d1`, `d=d2`, ... 라디오 그룹 버튼들이 생긴다.
모델은 리포트를 하나씩 가지고 있으며, 선택된 모델의 리포트를 보여주고, 거기서부터 사용자가 입력기를 통해 푸는 문제들은 해당 모델을 사용하도록 한다.
또한 입력기를 통해 받은 이항 응답은 선택 여부와 무관하게 **로드된 모든 모델**을 갱신하며, 각 모델의 궤적에 점을 추가한다.
모델 간 비교가 공정하려면 모두 같은 데이터를 먹어야 하기 때문이다.

`no model`이 선택된 경우 리포트를 보여주지 않으며, 출제는 기존 탐색 페이지와 동일하게 무작위다.

## 모델 리포트

모델 리포트는 모델이 이분 문제-답 쌍 하나를 학습할 때마다, 예측 성공률을 시간에 따른 궤적으로 갖는다.
궤적의 각 점은 두 값을 갖는다.

- Training Accuracy: 그 시점까지의 training set 전체에 대한 예측 성공률
- Validation Accuracy: 그 시점까지의 test set 전체에 대한 예측 성공률

해당 스텝에서 갱신되지 않은 쪽은 직전 값을 유지하며, 아직 한 번도 계산되지 않았으면 비어 있다.

두 궤적은 진행도에 따른 선 그래프 하나에 두 선으로 보여준다.
예측 성공률은 $p > 0.5$ 를 임계로 이진 예측한 값이 라벨과 일치한 비율이다.
