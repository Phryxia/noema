# 2026-08-24 llm 문서 전면 개편

## 문제

`llm/`은 34개 파일 4,912줄이었지만 "기능 X를 고쳐달라"는 요청을 받은 에이전트가 코드와 함정에 빨리 닿는 구조가 아니었다.

- 코드를 베낀 TS 선언·스키마 표가 코드보다 먼저 낡았다. `Relation` 유니온 사본 3개가 셋 다 다르게 틀렸고, v11에서 삭제된 `questions`가 5개 문서에 남았으며, `기획/저장-공통.md`의 "버전은 10", "같은 버전 백업만 허용", "각 인덱스는 한 유형만 담는다"가 틀렸다. 마지막 것은 믿으면 `type` 필터 누락 버그로 이어진다.
- `history/`(2,414줄)는 날짜 키 일지라 같은 함정이 재발했다. mousedown/blur 클릭 소실 4회, HMR + DB 버전 상수 소모 3회. "비-IDB Promise를 await하면 트랜잭션이 자동 커밋된다"는 저장 계층 최상위 규칙이 일지에만 있었다. `화면.md`는 목차에 없는 항목 8개가 시간순을 깨고 끝에 붙어 있었고, 제거된 임베딩 실험 항목 4개가 끊어진 링크를 안고 있었다.
- 기획/설계 구분이 작동하지 않았다(`기획/저장-공통.md`는 설계). 허브가 4단계로 쌓였고 루트 색인이 없었다. `기획.md`는 "네 문서"라 했지만 24개였다. 토스트·PWA·공통 헤더·localStorage 키는 문서 0건. `plan.md`의 줄 수는 전부 낡았고 제안한 "시기순 반분"은 `history/문서.md`가 이미 기각한 방식이었다.
- 전체 149 커밋 중 78건이 `llm/`을 건드렸다. 문서 유지 비용이 코드 작업과 맞먹었다.

## 해결

사용자 결정 네 가지를 따랐다. 트러블슈팅이 빠른 구조로 전면 개편, 일지는 삭제하지 않고 항목별 1파일로 무손실 분리(서브 에이전트), 반드시 참고할 지식은 증류 문서로 모으고 `CLAUDE.md`가 거기서부터 탐색하게, 코드 사본은 파일 경로 포인터로 대체.

- 기획/설계 축을 없애고 코드 디렉토리(관심사) 축으로 갔다. `기능/` 18개(1파일 = 코드 디렉토리 1~2개, 절 순서 고정: 코드/사양/결정 근거와 제약/알려진 함정/관련 문서/일지), `참고/` 5개(UI개발참고 확장, 입력-포커스참고·라우팅-쿼리참고·저장개발참고·검증참고 신설), `일지/` 82개 + 색인, `분석/`, `README.md`(요청 유형 -> 기능 문서 표, 작업 종류 -> 참고 문서 표), `개념.md`.
- 일지 분리는 서브 에이전트가 vite-node 스크립트로 했다. 원본별 "첫 heading~EOF" sha256과 분리 파일 결합 sha256이 바이트 단위로 같음을 확인한 뒤 원본을 지웠다. 일지 본문은 고치지 않았으므로 본문의 옛 경로 링크는 깨진 채이며, `일지/README.md` 끝의 옛 경로 -> 새 경로 대응표로 찾는다. 링크 검사는 `일지/`를 제외한다.
- 증류 문서 원료는 일지 본문이다. 항목마다 규칙 -> 증상 -> 해결 -> 출처(일지 링크). 기능 문서는 원본 절과 코드 파일을 대조해 직접 썼고, 서브 에이전트에는 문장을 쓰게 하지 않았다.
- 낡은 사실을 정정했다. 버전 11, `questions` 제거, 공유 인덱스의 `type` 필터, 컴포넌트명(`RecentSentences`/`RecentDocuments`, `WriterModeSelector` 제거), `sentenceCardList.ts` -> `extraction/cardList.ts`, `deleteRelation`은 `relations`만, `NonWordRelationTypes` 3종, `isExplorable` 플래그, 관계 정의("1개의 Lexis" -> 10종 + 추출 2종 + 태그). 중복 서술(삼항 중복 차단 4곳, 배치 색 규약 4곳, 대표 표현 5곳)을 각각 1곳으로 모았다.
- `CLAUDE.md` 「맥락 관리」를 문서 종류 표, 작업 전 읽는 순서, 작업 후 쓰는 순서, 쓰지 않는 것, 분량으로 다시 썼다. 말미 "검증에 관해"는 `참고/검증참고.md` 링크로.
- 검증: 깨진 링크 0(일지 제외), 코드 포인터 실존 0건 누락, ` ```ts ` 블록 0, 200줄 초과 0(일지 포함), 일지 81건 보존.
